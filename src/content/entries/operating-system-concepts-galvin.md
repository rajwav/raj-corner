### Why It Matters

An operating system is the most sophisticated illusion in computing. It takes bare copper, gates, and cache lines, and creates the seamless impression of concurrent processes, memory isolation, and persistent filesystems.

Studying Galvin gives a mental model of what actually happens between user code and CPU interrupt handlers—virtual memory paging, kernel-space transitions, race conditions, and deadlocks.
